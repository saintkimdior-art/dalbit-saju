# 🌙 달빛사주 — 직접 운영하기 안내서

이 폴더는 "달빛사주" 앱을 **내 인터넷 주소로 진짜 운영**할 때 쓰는 꾸러미예요.
천천히, 한 단계씩 따라 하면 돼요.

## 0. 폴더 안에 뭐가 있나요?

| 파일 | 하는 일 (쉽게 말하면) |
|---|---|
| `index.html` | 앱 그 자체. 화면·사주 계산·결제 버튼이 다 들어 있어요. |
| `netlify/functions/reading.js` | AI에게 풀이를 물어보는 **비밀 심부름꾼**. AI 열쇠(API 키)를 숨겨 줘요. |
| `netlify/functions/confirm.js` | 손님이 낸 돈이 **진짜 결제됐는지 확인**하는 계산대 직원. |
| `netlify.toml` | 위 심부름꾼들이 어디 사는지 적어 둔 주소록. |

## 1. 일단 내 주소로 올리기 (10분)

1. https://app.netlify.com 에 가입해요 (무료).
2. **Add new site → Deploy manually** 를 눌러요.
3. 이 폴더(`dalbit-saju`)를 통째로 끌어다 놓아요.
   - ⚠️ 서버 함수까지 쓰려면 끌어다 놓기 대신 GitHub에 올려 연결하거나 `npx netlify deploy --prod` 로 올려야 해요.
4. `https://내이름.netlify.app` 같은 주소가 생겨요. 휴대폰으로 열어 보세요!
5. 휴대폰에서 **공유 → 홈 화면에 추가**를 누르면 진짜 앱처럼 아이콘이 생겨요.

## 2. 진짜 AI 풀이 켜기

1. OpenAI(https://platform.openai.com) 또는 Google AI Studio(https://aistudio.google.com)에서 API 키를 받아요.
2. Netlify → Site configuration → **Environment variables** 에 넣어요.
   - `OPENAI_API_KEY` = sk-... (또는 `GEMINI_API_KEY` = AIza...)
3. 앱 오른쪽 위 ⚙️ 설정 → AI 종류를 **내 서버**로 바꾸고 저장해요.

> 💡 왜 키를 앱 설정에 바로 넣지 않나요? 앱 안에 넣은 열쇠는 손님 누구나 꺼내 볼 수 있어요. 서버에 넣으면 금고 안에 있는 것처럼 안전해요. (앱 설정에 직접 넣는 건 나 혼자 시험할 때만!)

## 3. 진짜 돈 받기 (토스페이먼츠)

1. **사업자등록**이 필요해요 (개인사업자 가능). 세무서나 홈택스에서 할 수 있어요.
2. https://developers.tosspayments.com 가입 → 처음엔 **테스트 키**가 바로 나와요.
   - 클라이언트 키 `test_ck_...` → 앱 ⚙️ 설정의 "토스페이먼츠 클라이언트 키"에
   - 시크릿 키 `test_sk_...` → Netlify 환경변수 `TOSS_SECRET_KEY` 에 (절대 앱에 넣지 않기!)
   - `PRICE` 환경변수 = 앱에서 정한 가격과 똑같이 (예: 2900)
3. 앱 ⚙️ 설정 → 결제 방식 **토스페이먼츠** 로 바꾸고 저장.
4. 테스트 키로 결제 → 토스 테스트 카드로 끝까지 해 보기 → 전체 풀이가 열리면 성공!
5. 토스에 **전자결제 계약(심사)** 신청 → 통과하면 `live_ck_`, `live_sk_` 키로 바꿔요. 이제 진짜 돈이 들어와요 💰

## 4. 결제가 흘러가는 길 (그림으로)

```
손님이 [결제하기] → 토스 결제창 → 카드 결제
      → 앱으로 돌아옴 → confirm.js가 토스에 "진짜 맞죠?" 확인
      → 토스 "네!" → 전체 풀이 열림
```

## 5. 꼭 알아 둘 것

- 운영 전에 **이용약관, 개인정보처리방침, 환불 규정**을 사이트에 올려야 해요 (토스 심사 때도 봐요).
- 사주 풀이는 "재미·참고용"이라고 안내하는 게 좋아요 (앱 맨 아래에 이미 있어요).
- 지금 "판매 기록"은 그 휴대폰에만 저장돼요. 손님이 많아지면 토스페이먼츠 관리자 화면에서 매출을 보세요.
- 지금 결제 잠금은 손님 휴대폰에 기억돼요. 더 단단하게 하려면 로그인·DB를 붙이는 다음 단계가 필요해요.
